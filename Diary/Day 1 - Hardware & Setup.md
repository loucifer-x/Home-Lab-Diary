### Overview

This project documents the process of building a home lab using Proxmox VE on repurposed hardware. The goal is to create a foundation for experimenting with virtualization, networking, and self-hosted services.

The hardware is modest by current standards, but sufficient for an initial setup and early-stage experimentation.

---

### Hardware Specification

| Component | Spec |
|---|---|
| CPU | Intel Core i5-6400 |
| RAM | 8 GB DDR4 |
| GPU | GeForce GTX 960 |
| Storage | 2 x 1 TB HDD |
| SSD (1) | Samsung 850 EVO 500 GB |
| SSD (2) | Samsung 840 EVO 500 GB |

This configuration provides enough headroom to install Proxmox VE and begin running virtual machines and containers.
